# Sessions

One file per cook session — the observed record behind every `dialed-in`
recipe and every yield in `docs/standing-parameters.md`.

Generated by `scripts/new-session.rb <slug>`, read back by
`scripts/session-report.rb <file>`. The workflow is in
[`docs/cook-session.md`](../docs/cook-session.md).

These are kept in git on purpose. When a yield in `standing-parameters.md`
looks wrong, this directory is how you find out which session put it there.
